# Corner Grocer Project

# Summarize the project and what problem it was solving.
For this project, I created a program for grocery stores to track which items have been purchased. The program reads a file that contains grocery items and counts how many times each item appears. Users can also search for specific items and see a histogram of the frequency of items purchased. The main goal was to help the grocery store better understand which products were being purchased most often.

# What did you do particularly well?
I think I did well with organizing the program and making it easy to use. I used a class to keep the different functions organized and a map to store the grocery items and their frequencies. I also made sure the menu was simple and straightforward so users can easily select the information they wanted to see.

# Where could you enhance your code? How would these improvements make your code more efficient, secure, and so on?
One improvement I could make would be adding more to handle unexpected user entries. This would help prevent errors if someone enters something other than the expected menu options. I could also improve how the program handles missing or incorrect files, that would make the program more reliable and easier to use.

# Which pieces of the code did you find most challenging to write, and how did you overcome this? What tools or resources are you adding to your support network?
One of the more challenging parts was working with input and output to make sure the program correctly counted each grocery item. I had to understand how the map stored information and how the different functions worked together. I worked through these challenges by reviewing the code, testing the program, and fixing errors as I found them. In the future, I can use course materials and and online programming resources when I need help.

# What skills from this project will be particularly transferable to other projects or course work?
Some of the most useful skills I learned were working with files, creating functions, and organizing code into classes. These are skills I can use in future programming assignments and other projects. I also gained more experience debugging and testing programs to make sure they work correctly.

# How did you make this program maintainable, readable, and adaptable?
I made the program easier to maintain by separating the different tasks into functions instead of putting everything into one large section of code. I also used names for functions and variables and added comments explaining what different parts of the code do. This makes the program easier to understand and allows changes to be made without having to rewrite the entire program.
